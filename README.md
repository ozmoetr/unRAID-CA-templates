# Unraid Templates

Community Applications templates for Unraid.

## Available Apps

### Testerfy
Spotify track rating app that lets you like/dislike tracks and automatically manages your library based on your ratings. Perfect for music discovery workflows.

- **Repository:** [ozmoetr/testerfy](https://github.com/ozmoetr/testerfy)
- **Docker Image:** `ghcr.io/ozmoetr/testerfy:latest`

## Installation

These templates are available through Unraid's Community Applications plugin.

1. Install the Community Applications plugin if you haven't already
2. Search for the app name in Community Apps
3. Click Install and configure

## Support

For issues with specific apps, please use the Issues page on each app's repository.
